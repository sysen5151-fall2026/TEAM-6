# Demo deck

`index.html` is a single, self-contained click-through presentation (no network needed).

- Next / back: buttons at the bottom, or the arrow keys, space and backspace.
- `MENU` (bottom left): short mode (7 key pages), auto-play, full screen, help.
- Language: button in the top-left corner (or key `L`). Opens in English; the Chinese version is translated, not machine-switched.
